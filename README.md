Hides the "Leaderboards" button added by Minimega on Legacy4J's title screen

Supported Re-Console targets: Minecraft 1.21.10, 26.1.2, and 26.2.

Build one target with `./gradlew build -Pmc=<version>` or all targets with
`./gradlew buildAll`.
